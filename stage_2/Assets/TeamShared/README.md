# TeamShared

통합 프로젝트(팀 프로젝트)에 있는 파일을 그대로 복사한 폴더입니다: `ItemData.cs`, 대화창·이름표 이미지, Galmuri9 폰트, 상단 UI 이미지(`Resources/TeamUI`).
GUID까지 같게 맞춰 두었기 때문에, 여기서 만든 아이템 에셋과 산책 화면이 통합 프로젝트에서도 팀 원본에 그대로 연결됩니다.

- 이 파일은 고치지 마세요. 팀 원본이 바뀌면 원본을 다시 복사해 오면 됩니다.
- 이 폴더는 합칠 때 옮기지 않습니다. 통합 프로젝트에는 원본이 이미 있습니다.
- 아이템 에셋(.asset)과 아이콘은 `Assets/Stage2Walk` 폴더 안에 만드세요. 예: `Assets/Stage2Walk/Items`

## 1스테이지 상단 UI 미리보기 (`TeamStatusBarPreview`)
- 실행하면 자동으로 1스테이지와 같은 상단 UI가 뜹니다: 상단 바, DAY, 하트 5개, 위험도 아이콘.
  - 이미지, 위치, 크기, 글자 크기는 팀 프리팹 `EXOD_PlayerStatusSystem`과 같은 값을 씁니다.
- DAY는 이 프로젝트의 일차(3분마다, 침대 클릭)를 따라갑니다.
- 하트와 위험도는 이 프로젝트에 팀 체력·위험도 시스템이 없어서 기본값(하트 5개, 안전)으로 나옵니다.
  - 테스트할 때는 `TeamStatusBarPreview.HP`, `Emergence`, `YanAppeared` 값을 바꾸면 됩니다.
- 통합 프로젝트에는 진짜 팀 UI가 있으므로, 이 폴더는 합칠 때 옮겨지지 않습니다.

## 1스테이지 아이템 칸 미리보기 (`TeamQuickSlotPreview`)
- 실행하면 자동으로 1스테이지와 같은 아래쪽 아이템 칸(퀵슬롯 바 + 10칸)이 뜹니다.
  - 이미지(`QuickSlot_1`), 위치, 크기는 팀 프리팹 `QuickSlotSystem`과 같은 값을 씁니다.
- 산책에서 얻은 아이템(`WalkItemPickup`)이 왼쪽 칸부터 들어갑니다. 아이콘이 없는 아이템은 이름으로 보입니다.
- 10칸이 다 차면 더 줍지 못합니다 (팀 퀵슬롯과 같은 규칙).
- 통합 프로젝트에는 진짜 팀 퀵슬롯이 있으므로, 이 폴더는 합칠 때 옮겨지지 않습니다.
