# Stage 2 산책(외출) 기믹 — 기본 메커니즘

## 테스트 방법
1. 유니티로 프로젝트를 열면 `Assets/Stage2Walk/Scenes`에 `Stage2_Home`, `Stage2_Walk` 씬이 자동으로 생성된다. 생성되지 않았다면 메뉴 **EXOD ▸ Stage 2 산책 ▸ 테스트 씬 생성**을 실행한다.
2. `Stage2_Home` 씬에서 Play를 누른다.
3. 갈색 **현관문**을 클릭하면 산책 씬으로 이동한다. **침대**를 클릭하면 바로 다음 날로 넘어간다.

## 규칙
| 항목 | 내용 |
|---|---|
| 일차 | 하루 시간은 **산책을 나간 뒤에만** 흐른다(집에 있을 때는 멈춤). 산책 중 1분이 다 지나면 다음 날로 넘어간다. 침대를 클릭해도 넘어간다. |
| 산책 시작 | 현관문을 클릭하면 시작한다. 산책 중에도 그날의 시간은 계속 흐른다. |
| 산책 목표 | 밤길 배경에서 1분 안에 **화면을 왼쪽 끝(집 대문)에서 오른쪽 끝까지 2번 왕복**한다. 화면은 저절로 움직인다(`WalkPlayerMover`의 `autoMove`, 끄면 A/D 또는 ←/→로 움직임). 플레이어는 화면에 보이지 않고, 화면 자체가 배경을 따라 좌우로 움직인다. 그녀는 항상 화면 가운데에 서 있다. 1분이 지나도 귀가하고, Esc를 누르면 중간에 그만둔다. |
| 상호작용 물체 | 집 대문, 가로등 4개, 벤치, 맨홀 2개, 물웅덩이, 버스 정류장. 배경 위에 투명한 판정 영역으로 놓여 있고, 마우스를 올리면 이름이 보인다. |
| 얀데레 | 화면 가운데에 서 있다. 무작위 시간이 지나면 스프라이트 1(앞을 봄)에서 스프라이트 2(뒤돌아봄)로 바뀐다. |
| 실패 | 그녀가 뒤돌아보고 있을 때 화면 아무 데나 클릭하면 실패한다. 스프라이트 3으로 바뀌고, 그날 시간에서 1분을 뺀 뒤 집으로 돌아간다. 다음 날까지 현관문을 쓸 수 없다. |
| 성공 | 집으로 돌아가 일차가 계속 진행된다. 하루 한 번 규칙에 따라 그날은 현관문이 잠긴다(`lockDoorAfterSuccess`로 끌 수 있다). |

에셋이 없는 동안에는 얀데레 색으로 상태가 표시된다. 흰색은 앞을 보는 상태, 노란색은 뒤돌아본 상태, 빨간색은 들킨 상태다.

## 에셋 / 아이템 넣기
- **얀데레 스프라이트**: `Yandere` 오브젝트의 `WalkYandere`에서 Sprite 1, 2, 3 칸에 넣는다. 뒤돌아보는 간격은 `awayDuration`, `watchingDuration`(최소~최대 초)으로 조절한다.
- **숨겨진 아이템이나 배경 물체**: 오브젝트에 Collider2D와 `WalkInteractable`을 붙인다. 들키지 않고 클릭했을 때 실행할 동작(아이템 획득 등)은 `onInteract` 이벤트에 연결한다. 한 번 주우면 사라지게 하려면 `disableAfterUse`를 켠다.
- **배경**: `Art/Bg_NightStreet.png`(5760×1080)를 Pixels Per Unit 108로 가져와 높이가 카메라에 꽉 차게 했다.
- **화면 이동**: `WalkPlayerMover`의 `moveScreen`(기본 켜짐)이 플레이어를 숨기고 화면(카메라)을 움직인다. 화면은 배경 높이에 꽉 차게 확대되고, 배경 밖은 보이지 않는 범위에서 좌우 끝까지 움직인다. 속도는 `moveSpeed`(기본 5, 16:9에서 4구간 약 28초)로 조절한다. `moveScreen`을 끄면 예전처럼 고정 화면에서 플레이어가 걷는다(이때 범위는 `WalkLeftEdge`, `WalkRightEdge`).
- **클릭 판정**: 빈 곳 클릭은 판정에서 빼고 물체 클릭만 실패로 치려면 `WalkGameManager`의 `anyClickCountsAsInteraction`을 끈다.

## 팀 프로젝트에 합칠 때
- `DayClock`의 `linkGManager`가 켜져 있으면 다음처럼 동작한다(GManager 코드는 고치지 않아도 된다).
  - `GManager`의 `Day` 값을 읽는다.
  - 1분이 지나면 `GManager.NextDay()`를 자동으로 호출한다.
- 대화창이 떠 있는 동안에는 하루 시간이 멈춘다(`DayClock`의 `pauseDuringDialogue`). 산책 대화창과 팀 `DialogueManager` 대화창 둘 다 해당된다.
  - 침대 등으로 `NextDay()`가 따로 호출되면 그것도 감지해서 1분 타이머를 다시 시작한다.
- 현관문 열기를 팀 조사·대화 시스템에서 처리하려면 `FrontDoorWalkStarter`의 `detectClickItself`를 끄고, 원하는 시점에 `TryStartWalk()`를 호출한다.
- 팀 아이템 줍기 코드에서 판정이 필요하면 `if (!WalkGameManager.ReportInteraction()) return;`를 사용한다. 들켰으면 false가 반환되고 산책이 끝난다.
- 산책 씬 이름은 `Stage2_Walk`다. 집 씬과 산책 씬이 모두 빌드 씬 목록(Build Profiles)에 등록되어 있어야 한다.
- 화면 좌상단의 글자는 임시 디버그 표시다. 각 컴포넌트의 `showDebugHud`를 끄면 숨겨진다.

## 화면 구성 (1스테이지와 맞춤)
- **대화**: 산책 시작, 들켰을 때, 끝날 때 그녀의 대사가 1스테이지와 같은 대화창과 이름표("여자친구")로 나옵니다. Space나 클릭으로 넘기고, 대화창이 떠 있는 동안에는 산책 시간과 그녀가 멈춥니다.
  - 통합 프로젝트에서는 팀 `DialogueManager`의 대화창이 그대로 쓰이고, 이 프로젝트에서는 같은 이미지·폰트·위치로 만든 `WalkDialogueBox`가 대신합니다.
  - 대사는 `Stage2_Walk` 씬의 `WalkGameManager`에서 고칩니다. 처음 산책, 매일 산책, 성공, 시간 초과, 그만둠, 들킴, 하루 끝 대사가 있습니다.
- **글꼴과 상자**: 모든 글자는 팀 폰트 Galmuri9를, 상자는 팀 이름표 이미지를 씁니다.
- **화면 배치**: 왼쪽 위에는 1스테이지와 똑같은 상단 UI(DAY·하트·위험도)가 나옵니다(`TeamShared/TeamStatusBarPreview`). 아래에는 1스테이지와 같은 아이템 칸이 나옵니다(`TeamShared/TeamQuickSlotPreview`).
  - 오른쪽 위: 그날 남은 시간(1분) 하나만 표시 (산책 시간·왕복 횟수 상자는 없앰)
  - 물체에 마우스를 올리면 이름표 상자로 이름이 보입니다.
- **전환**: 집과 산책 사이를 오갈 때 화면이 잠깐 어두워졌다 밝아집니다.
- 팀 이미지와 폰트는 `Assets/TeamShared`에 GUID까지 같게 복사해 두었습니다. 그래서 합친 뒤에는 팀 원본 에셋에 자동으로 연결됩니다. 설정은 `Stage2Walk/Resources/WalkUiTheme`에 있습니다.

## 산책 아이템 넣기
1. 메뉴 **Assets ▸ Create ▸ EXOD123 ▸ Items ▸ Item Data**로 아이템을 만듭니다. 위치는 `Assets/Stage2Walk/Items` 같은 `Stage2Walk` 폴더 안이어야 합니다.
   - `itemId`는 팀 공용 ID라서 다른 아이템과 겹치면 안 됩니다. 이름과 아이콘도 함께 넣습니다.
2. `Stage2_Walk` 씬에서 아이템을 숨길 물체(예: `Interactables/벤치`)를 선택하고 `WalkItemPickup`을 붙인 뒤, `item` 칸에 1번에서 만든 아이템을 넣습니다.
   - 새 장소에 숨기려면 빈 오브젝트를 만들고 `BoxCollider2D`, `WalkInteractable`, `WalkItemPickup`을 붙입니다.
3. 이 프로젝트에는 퀵슬롯이 없어서, 얻은 아이템은 화면 왼쪽 위 "주운 아이템"에만 표시됩니다. 통합 프로젝트에서는 팀 퀵슬롯에 바로 들어갑니다.
4. 한 번 얻은 아이템은 다음 날 산책에서는 나오지 않습니다.

## 통합 프로젝트와 합치기
이 프로젝트에서 계속 작업하다가, 나중에 통합 프로젝트에서 메뉴 하나로 합치면 됩니다.

1. 이 프로젝트에서 작업한 씬을 저장합니다.
2. 통합 프로젝트를 열고 메뉴 **EXOD ▸ Stage 2 산책 ▸ 스테이지2 프로젝트에서 가져오기 (합치기)**를 실행한 뒤 `EXOD_newstage2` 폴더를 선택합니다.
3. `Assets/Stage2Walk`의 스크립트, 이미지, 아이템, 산책 씬이 통합 프로젝트의 `Assets/EXODStage2Walk`로 덮어써집니다.
   - 공용 스크립트는 두 프로젝트에서 GUID까지 같게 맞춰 두었습니다. 그래서 산책 씬에 배치한 아이템, 스프라이트, 설정이 그대로 옮겨집니다.
   - 옮기지 않는 것: `Editor` 폴더, 테스트용 `Stage2_Home` 씬, `README.md`

### 합칠 때 어색해지지 않게 지킬 것
- 산책에 쓰는 이미지, 아이템, 프리팹은 모두 `Assets/Stage2Walk` 폴더 안에 두세요. 폴더 밖에 있는 것은 옮겨지지 않습니다. 빠진 것이 있으면 가져오기가 끝날 때 알려 줍니다.
- 스크립트 파일 이름을 바꾸거나 지웠다가 다시 만들지 마세요. GUID가 바뀌면 씬과의 연결이 끊어집니다. 내용은 마음대로 고쳐도 됩니다.
- `Stage2Walk` 폴더에서 지운 파일은 통합 프로젝트에서는 자동으로 지워지지 않습니다. 직접 지워 주세요.
- 1스테이지와 연결하는 코드(`Stage2HouseLink`)는 통합 프로젝트에만 있습니다. 이 프로젝트에서는 `Stage2_Home`의 현관문(`FrontDoorWalkStarter`)이 그 역할을 대신합니다.
